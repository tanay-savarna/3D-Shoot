# 3D SHOOT

## About the Game

3D Shoot is a 3D first-person shooter set in an arena. Survive, eliminate enemies and build up your score.

But there's more to it than just shooting.

Every kill brings you closer to unlocking new abilities. Whether you want to fire faster, launch yourself into the air or gain an advantage over your enemies, the choice is yours.

## Features

- **First-Person Gameplay** – Explore and fight from a fully 3D first-person perspective.
- **Enemy** – Face flying bat enemies that pursue and attack the player.
- **Health System** – Keep an eye on your health and avoid taking too much damage.
- **Scoring System** – Earn points for every enemy you eliminate.
- **Unlockable Abilities** – Reach kill milestones to unlock special abilities.
- **3D Arena** – Battle across a colourful arena featuring floating platforms and gaps.
- **Visual Effects** – Enjoy enemy hit effects, death animations and smoke effects.

### Requirements
- Godot 4
- A computer capable of running 3D games

### Running Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/tanay-savarna(my username)/3D-Shoot.git
   ```

2. Open Godot 4.
3. Select **Import**.
4. Navigate to the downloaded project folder.
5. Select `project.godot`.
6. Open the project and run it.
